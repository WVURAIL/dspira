Historical radio experiments

This package preserves 53 distinct original files represented by 55 historical
paths. The three LimeSDR interferometer copies have identical contents and
share one packaged file. manifest.json records all original paths and commits.

The files are references, not a supported software release. Their bytes, old
parameters, saved notebook outputs, and author notices are unchanged. Local
recordings named by notebooks are not supplied by this package. Inspect older
environments and missing inputs before attempting to run an experiment.

Use https://rail.wvu.edu/dspira/software/ for classroom applications and
https://rail.wvu.edu/dspira/research-examples/ for current research examples.

The source manifests and bundled notices record provenance; they do not assign
copyright or relicense the material. Individual file notices remain controlling.

Verify a file by comparing its SHA-256 with manifest.json.
