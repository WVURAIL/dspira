# Institute teaching resources

These files now have an ordinary home in the current DSPIRA repository.
Use the [teaching resources page](https://wvurail.org/dspira/teaching-resources/) to browse them.

The 2018 astronomy course was presented by Loren Anderson; the DSP course was presented by Natalia Schmid.
Slide authorship and embedded figure credits remain in the original files.
David J. Wilner prepared the Imaging and Deconvolution lecture for the 2014 Synthesis Imaging Workshop.

The numbered lecture3.pptx was selected over SP for RA Lecture 3.pptx.
It includes the corrected X(f) notation and an expanded Dirac-train explanation.
