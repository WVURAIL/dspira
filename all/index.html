Find construction guides, receiver setup, observing activities, and signal processing labs." --- {%- comment -%} Every lesson, grouped by module, in curriculum order. This is the only page that lists them all. Built on the WVU Design System (v3, Bootstrap 5.3 on a 24-column grid) with stock classes only — no site CSS. There used to be two: /lesson-modules/ rendered the same set with module photographs instead of summaries, which made "Modules" and "All lessons" two nav entries for one page. That URL redirects here now, and the photograph and blurb it carried are at the head of each section below. The filter box is progressive enhancement — assets/js/lessons.js reveals it and wires it up. With JavaScript off the box never appears and the full list is there to read. Hooks other things depend on, kept exactly as written: * class="module-toc__head" (one per module) and class="lesson-card" (one per lesson) are counted by CI (.github/workflows/build.yml); the Design System classes sit on the elements inside them. * data-lesson-filter, .filter__input, .filter__count, [data-module], .lesson-card[data-search] are what lessons.js queries. {%- endcomment -%}
