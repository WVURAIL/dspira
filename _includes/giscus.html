{%- comment -%} The comment box on a forum room. One argument, the room key from _data/giscus.yml, which is where the repository id, the category and the discussion title all live: {% include giscus.html room="dsp" %} Why data-mapping is "specific" rather than "pathname": pathname derives the discussion title from the URL, and every thread here was opened by utterances years ago under a title with no leading slash. If that derivation disagreed by a single character giscus would not error — it would quietly offer an empty thread and the old conversation would look deleted. Naming the discussion outright removes the guess, and it survives a room moving to a different URL. data-strict must stay "0". In strict mode giscus looks for a SHA-1 hash of the title inside the discussion body; these threads predate giscus and carry no such hash, so strict mode would find none of them. {%- endcomment -%} {%- assign this_room = site.data.giscus.rooms[include.room] -%}
{%- comment -%} The box is third-party JavaScript, which a school network is entirely capable of blocking. Without this the page would just end, with no sign a conversation exists at all. The utterances version had no fallback. {%- endcomment -%}
