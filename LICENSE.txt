WHAT THIS FILE USED TO SAY
--------------------------
It credited Sai Kiran Sripada, John Otander, animate.css and Basscss: the Jekyll
theme this site was built on, and the CSS framework that theme vendored. The
theme was replaced and all 22 Basscss partials deleted when css/style.scss was
written by hand, and none of those four has a line left in the repository.

They are removed rather than left in out of politeness. A notice file that lists
code which is not here is wrong in the same way as one that omits code which is,
and this file was managing both at once — the four font files the old
stylesheet self-hosted (Instrument Serif, Inter, JetBrains Mono, under the SIL
Open Font License) were being redistributed with no notice at all. The notice
this file then carried for them went in turn when the site moved to the WVU
Design System in 2026: its typefaces are served by Typekit, and no font file is
in the repository any more.
