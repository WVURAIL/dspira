--- layout: default --- {%- comment -%} Previous/next walk the lesson's own module, in curriculum order. A curriculum is read in module order, and the dates are publication dates — several lessons share one to the day — so a chronological pager was close to random: "Next" from the horn-construction overview used to be the two-horn interferometer. Every lesson now carries exactly one category and an `order`, so the chain through a module is unambiguous. Only core Liquid here — one sort and one pass over the sibling list — because GitHub Pages runs Jekyll 3.9 and anything newer fails the build silently, serving the last good copy of the site. {%- endcomment -%} {%- assign module = page.categories | first -%} {%- assign siblings = site.categories[module] | sort: 'order' -%} {%- assign found = false -%} {%- assign takenext = false -%} {%- for s in siblings -%} {%- if takenext %}{% assign nextpost = s %}{% assign takenext = false %}{% endif -%} {%- if s.url == page.url %}{% assign found = true %}{% assign takenext = true %}{% endif -%} {%- unless found %}{% assign prevpost = s %}{% endunless -%} {%- endfor -%}
