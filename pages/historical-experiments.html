These files record earlier experiments. Start with the current classroom software or research examples when choosing an application.

The collection contains {{ site.data.historical_experiments.files.size }} distinct files from {{ site.data.historical_experiments.source_path_count }} historical paths. Three copies of the same LimeSDR graph share one entry. Each original is downloadable from this website and remains unchanged, including saved notebook outputs and earlier hardware settings.

Download all historical experiments (ZIP, {{ site.data.historical_experiments.package.bytes | divided_by: 1000000.0 | round: 1 }} MB). The package includes source commits, checksums, and attribution notices.

Historical software may require older GNU Radio blocks, local paths, or data that are not included. The observed-pulsar recording and 40-foot telescope recording were not found in the preserved repositories. If you have a copy, attach it or share a download link in the corresponding issue. The catalog preserves their source and saved results; it does not establish that the experiments can be rerun.

The three earlier simulation datasets are different from the current reference samples. Both versions remain available. The small input file for the older dedispersion test is included; its expected original filename appears in the package manifest.
