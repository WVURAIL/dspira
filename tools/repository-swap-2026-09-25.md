# DSPIRA repository move, September 25, 2026

The active project keeps the `WVURAIL/dspira` name and the original lesson repository's 30 stars.
Its main branch preserves both projects' Git histories.
The current website files and lesson addresses remain the same.

All 11 discussions moved with their authors and 348 comments and replies.
The subject categories and open or closed states were preserved.
Seven empty opening posts received brief descriptions because GitHub requires a body when transferring a discussion.
